# 06 — Tratamiento de Datos Personales — Ley 19.628

## Criterio 2.1.5

### Tipos de datos comprometidos

| Tipo de dato | Ejemplo en el caso | Categoría (Ley 19.628) |
|---|---|---|
| Datos de identificación | Nombres, RUT, correos de funcionarios y pacientes | Dato personal |
| Datos de salud | Historiales médicos, diagnósticos, tratamientos (NHS) | **Dato sensible** |
| Datos financieros | Cuentas bancarias, tarjetas de crédito | **Dato sensible** |
| Datos operacionales | Archivos cifrados de sistemas corporativos | Dato personal |

Los datos de salud tienen protección reforzada bajo el Art. 2° letra g) Ley 19.628. Su tratamiento requiere consentimiento expreso del titular.

### Derechos ARCO aplicados al caso

**Acceso (Art. 12):** Las víctimas cuyos datos fueron comprometidos tenían derecho a saber qué información fue afectada.

**Rectificación (Art. 12):** Si el cifrado corrompió registros, las organizaciones debían restaurar y rectificar la información.

**Cancelación (Art. 12):** Las organizaciones deben eliminar datos que ya no requieran para minimizar el impacto de futuros ataques.

**Oposición (Art. 12):** Relevante cuando organizaciones trataban datos con fines no autorizados previo al ataque.

### Obligaciones del responsable (Art. 11)

- Adoptar medidas de seguridad para proteger los datos de accesos no autorizados.
- Garantizar la exactitud e integridad de los datos almacenados.
- No ceder los datos a terceros no autorizados.
- Informar al titular cuando sus datos hayan sido comprometidos (obligación reforzada en proyecto de nueva ley, Boletín 11.144-07).
